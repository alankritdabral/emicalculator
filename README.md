# EMI Calculator

A premium, modern, and beautiful EMI (Equated Monthly Installment) Calculator built with HTML, CSS, and Vanilla JavaScript. 

## Features

- **Modern UI:** Built with a glassmorphism aesthetic and smooth micro-animations.
- **Dark Mode First:** Sleek dark-themed design with vibrant gradients.
- **Real-time Calculation:** Instantly calculates monthly EMI based on the principal amount, interest rate, and tenure.
- **Comparison Feature:** Automatically compares your standard EMI against a special 9.99% interest rate to highlight potential savings or extra costs.
- **Zero Dependencies:** Fully built in vanilla web technologies. No React, Vue, or heavy frameworks required.

## Local Development

To run this project locally, you don't need any complex build steps. 

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
   - Alternatively, you can run a local server (e.g., `python3 -m http.server`) for a better development experience.

## Deployment to GitHub Pages

Since this project consists of static files (HTML, CSS, JS), deploying to GitHub Pages is incredibly simple.

1. **Create a GitHub Repository:** Push all these files (`index.html`, `styles.css`, `app.js`, `README.md`) to a new public or private repository on your GitHub account.
2. **Go to Settings:** Navigate to your repository's **Settings** tab.
3. **Pages Configuration:**
   - In the left sidebar, click on **Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and keep the folder as `/ (root)`.
   - Click **Save**.
4. **Access your site:** GitHub will start building your site. Once ready, the URL to your live EMI Calculator will be displayed at the top of the GitHub Pages settings page.
